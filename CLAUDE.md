# Proyecto de Seguimiento Diario

Proyecto personal de seguimiento diario para registrar y organizar:

- **Conceptos**: Ideas y definiciones clave aprendidas día a día
- **Sujetos**: Personas, autores, figuras relevantes encontradas en el estudio
- **Eventos**: Hechos históricos, actuales o académicos relevantes
- **Vocabulario**: Palabras nuevas, términos técnicos y sus definiciones

## Estructura

```
conceptos/       — Registro diario de conceptos
sujetos/         — Registro de personas y figuras relevantes
eventos/         — Registro de eventos
vocabulario/     — Registro de vocabulario nuevo
```

## Formato de archivos

Cada entrada se guarda en formato Markdown con la fecha como nombre de archivo (`YYYY-MM-DD.md`).

## Convenciones

- Idioma principal: Español
- Las entradas se organizan por fecha
- Cada archivo puede contener múltiples entradas del mismo día
- Usar encabezados H2 (`##`) para cada entrada individual dentro de un archivo diario
